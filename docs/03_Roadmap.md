# Project Roadmap

Project SP is a long-term engineering research project focused on understanding how classic digital samplers achieve their characteristic sound.

This roadmap outlines the major milestones of the project. The order may evolve as new discoveries are made, but the overall philosophy remains the same:

> Understand first. Build second.

---

# Phase 1 — Research & Documentation

## Objectives

- Study original service manuals and schematics
- Understand the complete signal path
- Document engineering decisions
- Build a solid theoretical foundation

### Status

🟢 In Progress

---

# Phase 2 — Analog Front-End

## Objectives

Design and document the complete analog input stage.

Topics include:

- Input protection
- Input impedance
- AC coupling
- Gain stage
- Operational amplifier selection
- Anti-alias filtering
- Noise considerations

### Status

⚪ Planned

---

# Long-Term Vision

Project SP is not intended to be a commercial product or a direct clone of any existing sampler.

Its purpose is to document, understand and recreate the engineering principles behind classic digital sampling systems while sharing that knowledge openly with the community.

Every completed phase should leave behind clear documentation that others can study, reproduce and improve.
