# Design Goals

## Purpose

Project SP is an open-source engineering research project focused on understanding how classic digital samplers create their unique sound.

The project combines analog electronics, digital signal processing and embedded software into a single educational platform.

---

## Primary Goals

- Understand the complete sampler signal path.
- Document every engineering decision.
- Build a modular hardware platform.
- Implement DSP algorithms from first principles.
- Validate designs through measurements and listening tests.
- Publish all documentation as open knowledge.

---

## Non-Goals

Project SP is **not** intended to become:

- a commercial product
- a one-to-one hardware clone
- a software plugin
- a reverse engineering project for commercial purposes

The objective is education, experimentation and engineering.

---

## Long-Term Vision

Create a modular sampler research platform capable of exploring the behaviour of classic hardware samplers while remaining fully documented and reproducible.

---

## Core Values

- Engineering first
- Documentation first
- Measurements over assumptions
- Understanding before implementation
- Open knowledge
